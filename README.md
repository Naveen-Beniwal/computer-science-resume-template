Every year, millions of Computer Science graduates submit resumes that never get read — not because their skills are weak, but because their formatting breaks ATS parsers before a human ever sees the document.

After studying how Applicant Tracking Systems actually parse resume data (fonts, column layouts, encoding), I built this template to be completely machine-readable while staying clean enough to impress human recruiters at top-tier companies.

This is not a Word document. It is a single-file LaTeX template that compiles to a pixel-perfect, 1-page PDF every time, with zero margin drift and zero encoding errors.

### ⚡ Why This Template Works: The Engineering Behind It

Most resume guides tell you *what to write*. This template fixes *how it is read by machines*.

**The 3 ATS-Killer Mistakes this template eliminates:**
1. **Two-column layouts:** Most resume builders use two columns. Almost every ATS parser reads left-to-right, top-to-bottom, turning two-column resumes into scrambled, unreadable text.
2. **Tables for layout:** Using HTML/Word tables to align content is invisible to you, but the ATS sees a completely mangled data structure.
3. **Non-standard fonts:** Decorative fonts often fail to encode properly in PDF, making your name and skills appear as blank characters to the parser.
